# Contributing to Student Marks Calculator

Thank you for your interest in contributing!
This is a beginner-level front-end project — all contributions are welcome.

---

## How to Contribute

### 1. Fork the Repository
Click **Fork** on the GitHub repository page.

### 2. Clone Your Fork
```bash
git clone https://github.com/your-username/student-marks-calculator.git
cd student-marks-calculator
```

### 3. Create a Branch
```bash
git checkout -b feature/your-feature-name
```

### 4. Make Your Changes
- Edit `index.html`, `css/style.css`, or `js/script.js` as needed.
- Follow existing code style (2-space indentation, clear variable names).
- Test by opening `index.html` in your browser.

### 5. Commit and Push
```bash
git add .
git commit -m "Add: short description of change"
git push origin feature/your-feature-name
```

### 6. Open a Pull Request
Go to the original repository on GitHub and click **New Pull Request**.

---

## What You Can Contribute

- Bug fixes
- UI or accessibility improvements
- Mobile responsiveness improvements
- New features (e.g. custom subject names, print result)
- Documentation improvements

## Please Do NOT

- Add login, authentication, or database features
- Add external libraries or CDN dependencies without discussion
- Change the grade calculation rules without justification
- Leave console.log statements, TODO comments, or placeholder code

---

## Code Style

| Rule          | Standard                              |
|---------------|---------------------------------------|
| Indentation   | 2 spaces                              |
| JavaScript    | Plain ES5/ES6 — no frameworks         |
| CSS           | External file (`css/style.css`)       |
| Naming (JS)   | camelCase                             |
| Naming (CSS)  | kebab-case                            |
